\section{Representaciones numéricas de la música}
\label{sec:dsp}

El procesamiento computacional del audio requiere extraer descriptores acústicos de la señal. Para esta tarea se emplearon bibliotecas de procesamiento digital de señales (DSP, por sus siglas en inglés). Estas herramientas transforman la onda sonora en arreglos matemáticos de una o dos dimensiones.

Entre las representaciones más útiles se encuentran el espectrograma y el cromagrama. El espectrograma refleja la variación de las frecuencias a lo largo del tiempo. Por su parte, el cromagrama captura la energía asociada a las doce clases de notas musicales. Un ejemplo de ambas transformaciones se ilustra en la figura \ref{fig:espectro_croma}.

\section{Información semántica del audio}
\label{sec:semantica}

Las representaciones numéricas de bajo nivel no siempre son suficientes para capturar conceptos musicales complejos. Por ello, se implementó una estrategia de aprendizaje por transferencia. Esta técnica consiste en utilizar modelos previamente entrenados con grandes volúmenes de datos para extraer características de alto nivel.

Para este fin se utilizó la biblioteca \textit{PANNs Inference}. Esta herramienta provee acceso a redes neuronales optimizadas para el análisis de sonido. De las opciones disponibles, se seleccionó la arquitectura denominada CNN14. Se trata de una red neuronal convolucional robusta, capaz de abstraer patrones semánticos profundos de la música. La estructura interna de esta arquitectura se detalla en la figura \ref{fig:cnn14}.

\section{Modelos de inteligencia artificial utilizados}
\label{sec:modelos}

Una vez obtenidas las características acústicas y semánticas, fue necesario aplicar algoritmos de predicción. El alcance del trabajo abarca problemas de clasificación y de regresión. Para resolverlos, se implementaron dos enfoques principales:

\begin{itemize}
    \item Redes MLP: Se diseñaron perceptrones multicapa para abordar los problemas de regresión multisalida. Estas redes neuronales artificiales demostraron eficacia para predecir variables continuas correlacionadas.
    \item Algoritmos LightGBM: Se integró el marco de trabajo \textit{LightGBM} para las tareas generales de clasificación multiclase y regresión simple. Esta herramienta se basa en el ensamble de árboles de decisión y destaca por su velocidad computacional.
\end{itemize}

\section{Despliegue e integración}

Se provisionó una instancia de cómputo en la nube, la cual garantiza la disponibilidad y los recursos de procesamiento necesarios.
